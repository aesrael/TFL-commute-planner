How does this work & is my location private?
How this works: your location is checked only on this device, only while the page is open, and is never sent anywhere. Turning an alert on asks your browser for location and notification permission, allow both for the full experience. Background alerts are best effort only, so keep the page open and screen on for reliable alerts.
Live times via TfL Unified API where available · parking lookup via Nominatim · route estimates via OSRM · verify before relying on them
